description: Display comprehensive repository information
agent: build
---

Display comprehensive GitHub repository information including:

- Repository name, remote URL, and branches
- Total commits and contributors
- Working tree status (modified, staged, untracked files)
- Latest commit details
- Recent commit history (last 7 commits)
- Project information from package.json
- Directory structure

Run the repo stats script:
!`npm run stats`

Format the output in a clear, readable way with all the repository statistics.
